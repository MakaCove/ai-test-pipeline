# 统一术语

所有技能和产物中一致使用以下术语。完整 Schema 见 `_shared/目录.md`。

## 编码体系（统一规则）

| 类型 | 格式 | 示例 |
|------|------|------|
| 主流程 | `FLOW-{MODULE}-{序号}` | `FLOW-ORDERS-001` |
| API 用例 | `TC-API-{MODULE}-{序号}` | `TC-API-ORDERS-001`、`TC-API-AUTH-001` |
| UI 用例 | `TC-FUNC-{MODULE}-{序号}` | `TC-FUNC-ORDERS-001`、`TC-FUNC-AUTH-001` |

> **已废弃编码**：`CTR-*`、`SCN-*`、`FEAT-*`、`TC-API-WF-*`、`TC-FUNC-WF-*`

## 基础

| 术语 | 定义 |
|------|------|
| **测试用例** | 唯一标识、模块、步骤/请求、断言、优先级，及 `trace` 链路分组。 |
| **接口测试用例** | HTTP 请求 + 响应断言；通过 `trace.flowRefs` 追溯主流程。 |
| **功能测试用例** | UI 交互步骤 + 断言；通过 `trace.flowRefs` 追溯主流程。 |
| **测试报告** | Markdown 执行结果：汇总 + 逐条通过/失败/跳过。 |
| **产物** | `test-artifacts/` 下的 JSON 用例、MD 报告、project-analysis。 |
| **模块** | 逻辑分组 id（如 `auth`、`orders`），**取自项目代码**。 |

## 流水线产物

| 术语 | 定义 | Schema |
|------|------|--------|
| **project-analysis** | 端点/路由/模块索引 + `mainFlowCandidates` + `stateHints` | `项目分析结构.md` |
| **mainFlowInventory** | 业务主流程清单（API/UI 生成依据） | `接口用例结构.md` / `功能用例结构.md` |
| **api-cases** / **functional-cases** | 可执行用例 JSON | 同上 |

## trace 分组（用例内链路字段）

所有用例统一使用 `trace` 对象包含链路字段：

| 字段 | 说明 |
|------|------|
| `trace.flowRefs` | 主流程 id 数组（`FLOW-*`），API/UI 通用 |
| `trace.dependsOn` | 上游用例 id 数组 |
| `trace.produces` | 本用例产出的变量名数组 |
| `trace.consumes` | 本用例消费的变量名数组 |

## 覆盖与验收

| 术语 | 定义 |
|------|------|
| **mainFlowCoveragePercent** | 主流程覆盖率；验收目标 **100%** |
| **orphanCases** | 无 `trace.flowRefs` 的用例数；应为 **0** |
| **flowChains** | 可串联场景覆盖统计（可选） |
| **scanLimitations** | project-analysis 中声明的本阶段未覆盖项 |

## 已废弃

| 废弃 | 替代 |
|------|------|
| `targetMinCases`、`≥ 2.5N`、固定条数 KPI | `mainFlowCoveragePercent = 100%` |
| 默认 JWT / admin/123admin | 从项目 `auth` 与配置**如实读取** |
| `contractRef` / `scenarioRef` / `featureRef` | `trace.flowRefs` |
| `CTR-*` / `SCN-*` / `FEAT-*` | `FLOW-*` + `TC-API/FUNC-*` |
| `flowRef`（单数） / `featureRefs` | `trace.flowRefs`（数组） |
| `endpointContracts` / `featureInventory` | `mainFlowInventory` + `mainFlowCandidates` |
