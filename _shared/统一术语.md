# 统一术语

所有技能和产物中一致使用以下术语。完整 Schema 见 `_shared/目录.md`。

## 基础

| 术语 | 定义 |
|------|------|
| **测试用例** | 唯一标识、模块、步骤/请求、断言、优先级，及追溯与链路字段。 |
| **接口测试用例** | HTTP 请求 + 响应断言；主流程模式追溯 `flowRef`。 |
| **功能测试用例** | UI 交互步骤 + 断言；主流程模式追溯 `featureRefs`。 |
| **测试报告** | Markdown 执行结果：汇总 + 逐条通过/失败/跳过。 |
| **产物** | `test-artifacts/` 下的 JSON 用例、MD 报告、project-analysis。 |
| **模块** | 逻辑分组 id（如 `auth`、`orders`），**取自项目代码**。 |

## 流水线产物

| 术语 | 定义 | Schema |
|------|------|--------|
| **project-analysis** | 端点/路由/模块**索引地图** | `项目分析结构.md` |
| **mainFlowInventory** | 业务主流程清单（API/UI 生成依据） | `接口用例结构.md` / `功能用例结构.md` |
| **api-cases** / **functional-cases** | 可执行用例 JSON | 同上 |

## 追溯字段（主流程模式 · 当前默认）

| 字段 | 用于 | 说明 |
|------|------|------|
| **flowRef** | 接口 WF 用例 | 指向 `mainFlowInventory[].id`（`FLOW-*`） |
| **featureRefs** | 功能 WF 用例 | 指向 `mainFlowInventory[].id`（`FLOW-*`） |
| **dependsOnCases** | 链路用例 | 依赖的上游用例 id |
| **produces** / **consumes** | 链路用例 | 变量产出/消费 |
| **steps.saveAs** / **steps.useVar** | 功能步骤级链路 | 步骤变量 |
| **sourceAnalysis** | 元信息 | 引用的 project-analysis 路径 |

## 追溯字段（可选 · 细粒度扩展）

| 字段 | 说明 |
|------|------|
| **contractRef** / **scenarioRef** | 契约场景模式（非主流程默认验收） |
| **featureRef** | 单功能点 id（`featureInventory`） |
| **endpointContracts** / **featureInventory** | 全量契约/功能清单 |

## 覆盖与验收

| 术语 | 定义 |
|------|------|
| **mainFlowCoveragePercent** | 主流程覆盖率；验收目标 **100%** |
| **orphanCases** | 无追溯字段的用例数；应为 **0** |
| **flowChains** | 可串联场景覆盖统计（可选） |
| **scanLimitations** | project-analysis 中声明的本阶段未覆盖项 |

## 已废弃

| 废弃 | 替代 |
|------|------|
| `targetMinCases`、`≥ 2.5N`、固定条数 KPI | `mainFlowCoveragePercent = 100%` |
| 默认 JWT / admin/123admin | 从项目 `auth` 与配置**如实读取** |
| `contractScenarioCoveragePercent` 作为主验收 | `mainFlowCoveragePercent`（除非用户要求契约全覆盖） |
