# 统一术语

所有技能和产物中一致使用以下术语。

## 基础

| 术语 | 定义 |
|------|------|
| **测试用例** | 一个完整测试场景：唯一标识、模块、标题、描述、前置条件、步骤/请求、断言、优先级、标签，及追溯字段（见下）。 |
| **接口测试用例** | 发送 HTTP 请求并验证响应的用例；追溯 `contractRef` + `scenarioRef`。 |
| **功能测试用例** | 描述用户可见场景、通过 UI 交互验证的用例；追溯 `featureRef` 或 `featureRefs`。 |
| **测试套件** | 按模块或功能分组的一组测试用例。 |
| **测试执行** | 对一组用例的一次完整运行。 |
| **测试报告** | 执行结果：汇总统计 + 逐条通过/失败/跳过及证据。 |
| **产物** | 持久化输出文件（JSON 用例、MD 报告、project-analysis）。 |
| **断言** | 单条验证规则（如 status=200、元素可见）。 |
| **优先级** | `P0`（致命）、`P1`（高）、`P2`（中）、`P3`（低）。 |
| **模块** | 用例的逻辑分组，小写英文 id（如 `auth`、`orders`），**取自项目代码**。 |

## 流水线三阶段产物

| 术语 | 定义 | Schema 文件 |
|------|------|-------------|
| **项目分析** / **project-analysis** | 流水线第一步：端点/路由/模块**索引地图**；非最终契约。 | `项目分析结构.md` |
| **端点契约清单** / **endpointContracts** | 接口用例生成前：每端点的请求/响应/校验/业务规则及 **scenarios[]**。 | `接口用例结构.md` |
| **功能清单** / **featureInventory** | 功能用例生成前：每路由/页面的可测交互功能点列表。 | `功能用例结构.md` |

## 追溯字段

| 字段 | 用于 | 说明 |
|------|------|------|
| **contractRef** | 接口用例 | 指向 `endpointContracts[].id`（如 `CTR-ORDERS-POST-001`） |
| **contractRefs** | 接口流程用例 | 多个契约 id |
| **scenarioRef** | 接口用例 | 指向 `scenarios[].id`（如 `SCN-HAPPY`） |
| **featureRef** | 功能用例 | 指向 `featureInventory[].id`（如 `FEAT-AUTH-001`） |
| **featureRefs** | 功能流程用例 | 多个功能点 id |
| **sourceAnalysis** | 用例元信息 | 引用的 `project-analysis-*.json` 路径 |
| **relatedApis** | 功能用例（可选） | 该场景涉及的 API，便于与接口用例对照 |

## 覆盖与验收

| 术语 | 定义 |
|------|------|
| **contractScenarioCoveragePercent** | P0 契约场景被用例覆盖的比例；验收目标 **100%** |
| **featureCoveragePercent** | P0 功能点被用例覆盖的比例；验收目标 **100%** |
| **orphanCases** | 无追溯字段的「孤儿」用例数；应为 **0**（workflow 须显式标注） |
| **scanLimitations** | project-analysis 中声明的本阶段未覆盖项 |

## 设计方法（tags / designMethods）

| 术语 | 说明 |
|------|------|
| **等价类** | 有效/无效输入划分 |
| **边界值** | 长度、分页、数值边界 |
| **判定表** | 多条件组合 |
| **状态迁移** | 状态机前后态 |
| **用例场景** | 跨步骤主成功/扩展流 |
| **错误推测** | 易错操作、重复提交 |
| **检查清单** | 冒烟关键项 |
| **Pairwise** | 两两组合降维 |

详见各 generate 技能的 `07_*设计方法.md`。
