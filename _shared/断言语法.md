# 断言语法

接口测试和功能测试共用一套断言语法规范。

## 接口断言

每条断言是一个 JSON 对象：

```json
{
  "field": "status",
  "operator": "eq",
  "expected": 200
}
```

### 操作符

| 操作符 | 含义 | 示例 |
|--------|------|------|
| `eq` | 等于 | `"status": 200` |
| `neq` | 不等于 | `"status": 403` |
| `contains` | 响应体/字段包含指定字符串 | `"body": "token"` |
| `not_contains` | 响应体/字段不包含指定字符串 | `"body": "error"` |
| `gt` | 大于 | `"body.data.total": 0` |
| `lt` | 小于 | `"body.data.total": 100` |
| `exists` | 字段存在且不为 null | `"body.data.id"` |
| `not_exists` | 字段不存在或为 null | `"body.error"` |
| `regex` | 匹配正则表达式 | `"body.token": "^[A-Za-z0-9-_]+\\.[A-Za-z0-9-_]+\\.[A-Za-z0-9-_]*$"` |
| `type` | 类型匹配（`string`/`number`/`boolean`/`object`/`array`/`null`） | `"body.data.list": "array"` |

### 字段路径

使用点号访问嵌套 JSON：`body.data.items[0].name`。

### `type` 判定说明

- `array`：使用 `Array.isArray(实际值)` 判定。
- `null`：判定 `实际值 === null`。
- 其它类型按 JavaScript `typeof` 判定（如 `string`、`number`、`boolean`、`object`）。

## 功能断言

功能断言描述预期的 UI 状态：

```json
{
  "type": "element_visible",
  "target": "登录按钮",
  "expected": true
}
```

### 断言类型

| 类型 | 含义 |
|------|------|
| `element_visible` | 指定 UI 元素可见 |
| `element_hidden` | 指定 UI 元素不可见 |
| `text_contains` | 页面包含指定文本 |
| `text_not_contains` | 页面不包含指定文本 |
| `url_equals` | 当前 URL 完全匹配 |
| `url_contains` | 当前 URL 包含指定路径 |
| `count_gte` | 匹配元素数量 ≥ 预期值 |
| `count_eq` | 匹配元素数量 = 预期值 |
