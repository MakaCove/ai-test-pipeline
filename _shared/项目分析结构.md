# 项目分析结构

`project-analysis-*.json` 是流水线**第一步**产物：端点/路由/模块**索引地图**，非最终 API/UI 契约。

- 生成技能：`project-analyzer`
- 详细工作流：`project-analyzer/02_执行工作流.md`、`05_多栈扫描指南.md`
- 下游衔接：`project-analyzer/06_下游衔接.md`

## 文件

- **路径**：`test-artifacts/project-analysis-{yyyyMMdd-HHmmss}.json`
- **schema**：`ai-test-pipeline/project-analysis/v1`
- **编码**：UTF-8，2 空格缩进

## 顶层结构

```json
{
  "schema": "ai-test-pipeline/project-analysis/v1",
  "generatedAt": "2026-05-28T15:00:00+08:00",
  "project": { },
  "auth": { },
  "scanLimitations": [],
  "chainHints": { },
  "downstream": { },
  "modules": [],
  "summary": { }
}
```

## project

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | ✅ | 项目名称 |
| `type` | ✅ | `前后端分离` \| `全栈单体` \| `纯后端` \| `纯前端` |
| `backend.language` | 条件 | 实际栈描述，**勿写死** Spring |
| `backend.baseUrl` | ✅ | 如 `http://localhost:8080` |
| `backend.apiPrefix` | 推荐 | 如 `/api/v1` |
| `backend.entryFileCount` | 推荐 | Controller/Router 入口文件数 |
| `frontend.framework` | 条件 | 实际栈描述 |
| `frontend.baseUrl` | 条件 | 如 `http://localhost:5173` |

## auth

| 字段 | 必填 | 说明 |
|------|------|------|
| `type` | ✅ | **从代码识别**：JWT Bearer、Bearer 会话 UUID、Session Cookie、API Key、`none` 等 |
| `loginEndpoint` | 推荐 | `{ method, path }` |
| `tokenHeader` | 推荐 | 如 `Authorization` |
| `tokenFormat` | 推荐 | 如 `Bearer {token}` |
| `publicEndpoints` | 推荐 | 匿名/白名单路径数组 |
| `testAccount` | 推荐 | `{ username, password }`；找不到则 `null` |

## scanLimitations（必填）

本阶段**未覆盖**的内容，防止下游误把 analysis 当完整契约：

```json
[
  "未解析 DTO 校验注解，requestBody 仅为 Controller 参数名",
  "routes.summary 为路由级概览，未逐控件扫描"
]
```

## chainHints（推荐）

用于向下游提供“可串联场景”的线索，帮助生成技能快速建立 `flowChains`、`dependsOnCases` 与 `produces/consumes`。

```json
{
  "chainHints": {
    "enabled": true,
    "candidateChains": [
      {
        "id": "CH-ORDERS-LIFECYCLE",
        "module": "orders",
        "type": "resource-lifecycle",
        "producerEndpoints": ["POST /api/v1/orders"],
        "consumerEndpoints": [
          "GET /api/v1/orders/{id}",
          "PUT /api/v1/orders/{id}",
          "DELETE /api/v1/orders/{id}"
        ],
        "suggestedVars": ["orderId"],
        "confidence": "high"
      }
    ],
    "crossModuleRefs": [
      {
        "fromModule": "projects",
        "toModule": "versions",
        "via": "projectId",
        "source": "path-param"
      }
    ]
  }
}
```

### 字段说明

| 字段 | 说明 |
|------|------|
| `enabled` | 是否输出链路线索 |
| `candidateChains[]` | 同模块内可串联候选链 |
| `candidateChains[].type` | `resource-lifecycle` / `auth-context` / `state-transition` / `workflow` |
| `producerEndpoints[]` | 产出型端点（create/login/start） |
| `consumerEndpoints[]` | 消费型端点（query/update/delete/action） |
| `suggestedVars[]` | 推荐变量名（如 `token`、`projectId`） |
| `confidence` | `high` / `medium` / `low` |
| `crossModuleRefs[]` | 跨模块依赖提示（用于 workflow 编排） |

`chainHints` 为推荐字段，不替代下游读源码与契约/功能清单构建。

## downstream（推荐）

指向下游 generate 技能须读的源码路径：

```json
{
  "apiTestCaseGenerate": {
    "readPaths": ["backend/**/controller/", "backend/**/dto/"],
    "buildArtifact": "coverage.endpointContracts"
  },
  "functionalTestCaseGenerate": {
    "readPaths": ["frontend/src/router/", "frontend/src/views/"],
    "buildArtifact": "coverage.featureInventory"
  }
}
```

路径按**实际仓库**填写。

## modules[]

| 字段 | 说明 |
|------|------|
| `name` | 模块 id，小写英文，**取自代码** |
| `displayName` | 中文展示名 |
| `priority` | P0/P1/P2 |
| `endpoints[]` | 该模块 API 端点 |
| `routes[]` | 该模块前端路由 |

### endpoints[] 字段

| 字段 | 可信度 | 说明 |
|------|--------|------|
| `method`, `path` | 高 | HTTP 方法与完整路径 |
| `summary` | 中 | 简要说明 |
| `requiresAuth` | 中 | 是否需登录 |
| `requestBody`, `responseBody` | **低** | 初步字段名；完整契约见 `endpointContracts` |
| `priority` | — | P0/P1/P2 |
| `sourceFile` | 推荐 | Controller 文件名，便于下游定位 |

### routes[] 字段

| 字段 | 说明 |
|------|------|
| `path` | 路由 path |
| `name` | 路由 name |
| `requiresAuth` | 是否需登录 |
| `summary` | 打开组件后的 1 句交互概览 |
| `component` | 推荐，页面组件相对路径 |

## summary

| 字段 | 说明 |
|------|------|
| `totalEndpoints` | 端点总数（**不是**接口用例条数目标） |
| `totalRoutes` | 路由总数（**不是**功能用例条数目标） |
| `totalModules` | 模块数 |
| `coreModules` | 核心模块 id 列表 |
| `auxiliaryModules` | 辅助模块 id 列表 |

## 与下游产物的关系

```
project-analysis.json
  ├─ modules[].endpoints  ──→  api-cases meta.coverage.endpointContracts（读 DTO 补全）
  ├─ chainHints            ──→  api-cases/functional-cases 的 flowChains 线索
  └─ modules[].routes       ──→  functional-cases meta.coverage.featureInventory（读 View 补全）
```
