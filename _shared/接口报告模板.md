# 接口测试报告模板

生成接口测试报告时使用此模板。将 `{{占位符}}` 替换为实际数据。

```markdown
# 接口测试报告

**生成时间**：{{generatedAt}}
**用例来源**：{{caseFile}}
**项目分析**：{{sourceAnalysis}}
**执行环境**：{{baseUrl}}

---

## 概览

| 指标 | 数值 |
|------|------|
| 总用例数 | {{total}} |
| 通过 | {{passed}} |
| 失败 | {{failed}} |
| 跳过 | {{skipped}} |
| 通过率 | {{passRate}}% |
| 执行耗时 | {{duration}} |

---

## 契约覆盖（来自用例 meta.coverage）

| 指标 | 数值 |
|------|------|
| 端点覆盖 | {{endpointsCovered}} / {{endpointTotal}}（{{endpointCoveragePercent}}%） |
| P0 契约场景覆盖 | {{contractScenariosCovered}} / {{contractScenarioTotal}}（{{contractScenarioCoveragePercent}}%） |
| 未覆盖场景 | {{uncoveredScenarios}} |
| 孤儿用例数 | {{orphanCases}} |

---

## 链路覆盖（可选，来自用例 meta.coverage.flowChains）

| 指标 | 数值 |
|------|------|
| 链路场景覆盖 | {{chainScenarioCovered}} / {{chainScenarioTotal}}（{{chainScenarioCoveragePercent}}%） |
| 链路用例通过 | {{chainPassed}} / {{chainTotal}}（{{chainPassRate}}%） |
| 链路失败摘要 | {{chainFailureSummary}} |

---

## 失败用例

{{#each failures}}

### {{id}} — {{title}}

- **模块**：{{module}}
- **优先级**：{{priority}}
- **契约追溯**：{{contractRef}} / {{scenarioRef}}
- **请求**：`{{method}} {{path}}`
- **预期**：{{expectedSummary}}
- **实际**：{{actualSummary}}
- **错误信息**：{{error}}

---

{{/each}}

## 全部用例明细

| ID | 模块 | 标题 | 契约/场景 | 优先级 | 结果 | 耗时 |
|----|------|------|-----------|--------|------|------|
{{#each allCases}}
| {{id}} | {{module}} | {{title}} | {{contractRef}}/{{scenarioRef}} | {{priority}} | {{statusIcon}} | {{duration}}ms |
{{/each}}

---

## 备注

{{notes}}
```

## 说明

- **契约覆盖**块从 `api-cases-*.json` 首元素 `coverage` 读取，与执行结果并列展示。
- **链路覆盖**块在 `flowChains` 存在时展示；无链路场景可显示 `N/A`。
- 验收关注 **P0 契约场景 100% 覆盖**及执行通过率，不以总用例数论达标。
