# 产物目录布局

所有测试产物统一写入项目根目录下的 `test-artifacts/`。

```
test-artifacts/
├── project-analysis-{yyyyMMdd-HHmmss}.json   # 项目分析（地图级索引）
├── api-cases/
│   └── api-cases-{yyyyMMdd-HHmmss}.json      # 接口用例 + endpointContracts
├── functional-cases/
│   └── functional-cases-{yyyyMMdd-HHmmss}.json  # 功能用例 + featureInventory
├── api-reports/
│   └── api-report-{yyyyMMdd-HHmmss}.md
├── ui-reports/
│   ├── ui-report-{yyyyMMdd-HHmmss}.md
│   ├── ui-results-{yyyyMMdd-HHmmss}.json     # 可选：Playwright 执行明细
│   └── screenshots/
│       └── {用例ID}_{tag}_{时间戳}.png
├── ui-test.config.json                       # UI 浏览器 profile（见 ui-test-profile模板.md）
├── scripts/
│   └── run-functional-tests.mjs              # Playwright 功能用例执行器
└── latest                                    # 指向最新时间戳的指针文件
```

```
scripts/
├── validate-api-cases.mjs                    # API 用例机检（支持 --strict / --enforce-chain）
└── validate-functional-cases.mjs             # UI/功能用例机检（支持 --strict / --enforce-chain）
```

## Schema 索引（_shared）

| 产物 | schema 值 | 结构定义 |
|------|-----------|----------|
| 项目分析 | `ai-test-pipeline/project-analysis/v1` | `项目分析结构.md` |
| 接口用例 | `ai-test-pipeline/api-case/v1` | `接口用例结构.md` |
| 功能用例 | `ai-test-pipeline/functional-case/v1` | `功能用例结构.md` |
| 断言 | — | `断言语法.md` |
| 报告 | — | `接口报告模板.md`、`界面报告模板.md` |

## 数据流

```
project-analysis.json          ← project-analyzer
       │
       ├─→ api-cases.json      ← endpointContracts + contractRef/scenarioRef + flowChains
       └─→ functional-cases.json  ← featureInventory + featureRef/featureRefs + flowChains
              │
              ├─→ api-report.md
              └─→ ui-report.md
```

## 约定

- **时间戳格式**：`yyyyMMdd-HHmmss`，例如 `20260528-142300`。
- **latest 指针**：每次生成新产物后，更新 `test-artifacts/latest` 为当前时间戳字符串；下游通过读取此文件定位最新产物。
- **JSON 用例文件**：顶层为**数组**；首元素为元信息（含 `coverage`），其余为用例对象。
- **JSON 分析文件**：顶层为**对象**（非数组）。
- **MD 报告**：自包含 Markdown，内嵌统计、覆盖指标、用例明细及截图引用。

## 元信息必填 coverage 块

| 产物 | coverage 核心字段 |
|------|-------------------|
| api-cases | `endpointContracts`、`contractScenarioCoveragePercent`、`flowChains`（可选） |
| functional-cases | `featureInventory`、`featureCoveragePercent`、`flowChains`（可选） |

用例条数（`totalCases`）为统计结果，**不是**验收 KPI。
