# UI 测试报告模板

生成 UI 测试报告时使用此模板。将 `{{占位符}}` 替换为实际数据。

```markdown
# UI 测试报告

**生成时间**：{{generatedAt}}
**用例来源**：{{caseFile}}
**项目分析**：{{sourceAnalysis}}
**测试地址**：{{baseUrl}}
**浏览器**：{{browser}}

---

## 概览

| 指标 | 数值 |
|------|------|
| 总用例数 | {{total}} |
| 通过 | {{passed}} |
| 失败 | {{failed}} |
| 跳过 | {{skipped}} |
| 通过率 | {{passRate}}% |
| 执行耗时 | {{duration}} |

---

## 覆盖统计（来自用例 meta.coverage）

| 指标 | 数值 |
|------|------|
| 主流程覆盖 | {{mainFlowsCovered}} / {{mainFlowTotal}}（{{mainFlowCoveragePercent}}%） |
| 未覆盖主流程 | {{uncoveredMainFlows}} |
| 孤儿用例数 | {{orphanCases}} |

> 若用例为旧版细粒度模式，可改填路由/功能点覆盖行。

---

## 链路覆盖（可选，来自用例 meta.coverage.flowChains）

| 指标 | 数值 |
|------|------|
| 链路场景覆盖 | {{chainScenarioCovered}} / {{chainScenarioTotal}}（{{chainScenarioCoveragePercent}}%） |
| 链路用例通过 | {{chainPassed}} / {{chainTotal}}（{{chainPassRate}}%） |
| 链路失败摘要 | {{chainFailureSummary}} |

---

## 失败用例

{{#each failures}}

### {{id}} — {{title}}

- **模块**：{{module}}
- **优先级**：{{priority}}
- **主流程追溯**：{{flowRefs}}
- **失败的断言**：{{failedAssertion}}
- **截图**：{{screenshotPath}}
- **错误信息**：{{error}}

---

{{/each}}

## 全部用例明细

| ID | 模块 | 标题 | 主流程 | 优先级 | 结果 | 耗时 | 截图 |
|----|------|------|--------|--------|------|------|------|
{{#each allCases}}
| {{id}} | {{module}} | {{title}} | {{flowRefs}} | {{priority}} | {{statusIcon}} | {{duration}}s | {{screenshotLink}} |
{{/each}}

---

## 备注

{{notes}}
```

## 说明

- **功能覆盖**块从 `functional-cases-*.json` 首元素 `coverage` 读取。
- **链路覆盖**块在 `flowChains` 存在时展示；无链路场景可显示 `N/A`。
- 验收关注 **主流程 100% 覆盖**及执行通过率，不以总用例数与路由数比较。
