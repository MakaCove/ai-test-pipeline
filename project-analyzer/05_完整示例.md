# 完整示例

> 虚构的「订单管理系统」，仅演示 JSON 结构。模块名、认证方式、字段名请勿复制到无关项目。

## 背景

演示 `project-analyzer` 如何从 Spring + Vue 项目扫描出端点/路由索引、链路线索与主流程候选。

## 输入

### 后端 — OrderController.java（Spring）

```java
@RestController
@RequestMapping("/api/v1/orders")
public class OrderController {
    @GetMapping
    public Result<PageVO<OrderVO>> list(PageQuery query) { ... }

    @PostMapping
    public Result<OrderVO> create(@RequestBody @Valid CreateOrderDTO dto) { ... }

    @GetMapping("/{id}")
    public Result<OrderVO> getById(@PathVariable Long id) { ... }
}
```

### 前端 — router/index.ts（Vue 3）

```typescript
const routes = [
  { path: '/login', component: () => import('@/views/Login.vue') },
  { path: '/orders', component: () => import('@/views/OrderList.vue'), meta: { requiresAuth: true } },
];
```

## 关键字段说明

| 字段 | 说明 |
|------|------|
| `scanLimitations` | 本阶段未覆盖项，防止下游误用 |
| `chainHints` | 可串联场景的端点线索 |
| `mainFlowCandidates` | 主流程候选（完整文件中还包含此字段） |
| `modules[].endpoints[]` | 后端 API 索引 |
| `modules[].routes[]` | 前端路由索引 |

## 验收点

- [ ] `schema` 为 `ai-test-pipeline/project-analysis/v2`
- [ ] `scanLimitations` 非空且如实
- [ ] `auth.testAccount` 找不到时为 `null`，不硬编码
- [ ] 端点/路由索引与源码一致
- [ ] 下游 generate 技能可据此构建 `mainFlowInventory`
