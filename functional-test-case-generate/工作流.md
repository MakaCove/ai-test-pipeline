# UI 用例生成 — 工作流

## 输入与范围

| 来源 | 用途 |
|------|------|
| `project-analysis` | routes、auth、chainHints、pageEntryHints、mainFlowCandidates |
| 布局/侧栏 | `routeMenuMap`（见 [菜单导航与步骤.md](菜单导航与步骤.md)） |
| 主流程页面源码 | 按钮、表单、业务动词 |
| `api/`、`services/` | 判断创建/提交/流转动作 |

**产出**：`mainFlowInventory` + JSON 用例。

**默认不做**：单字段校验、分页筛选组合、全路由穷举。

---

## 执行步骤

```
- [ ] 1. 读 project-analysis（含 mainFlowCandidates、pageEntryHints）
- [ ] 2. 建立 routeMenuMap
- [ ] 3. 确认/扩展 mainFlowCandidates → mainFlowInventory
- [ ] 4. 菜单遍历法兜底检查（见 主流程识别与设计.md §5）
- [ ] 5. 编写用例（TC-FUNC-AUTH-* + TC-FUNC-{MODULE}-{序号}）
- [ ] 6. 智能编排（见 智能编排.md）
- [ ] 7. 验收（见 验收与输出.md）
- [ ] 8. 写入 test-artifacts/functional-cases/ 并更新 latest
```

### 步骤 2：routeMenuMap

从布局组件提取侧栏**可见文案**与 route；`/login` 标注 `navigation.type: direct`。

### 步骤 3：识别主流程

优先确认 `mainFlowCandidates` 和 `pageEntryHints[].actions`；数量不设上限；只读主流程涉及页面。

### 步骤 5：编写用例

- 仅允许：`TC-FUNC-AUTH-*`（登录）与 `TC-FUNC-{MODULE}-{序号}`（主流程）
- 登录：`TC-FUNC-AUTH-001`，`trace.produces: ["sessionUser"]`
- 主流程：`ensure_session` → `click_menu` → 连续操作；`trace.flowRefs` → `FLOW-*`
- 步骤与断言规则见 [菜单导航与步骤.md](菜单导航与步骤.md)

### 步骤 8：落盘

- `test-artifacts/functional-cases/functional-cases-{yyyyMMdd-HHmmss}.json`
- Schema：`_shared/功能用例结构.md`
