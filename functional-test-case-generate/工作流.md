# UI 用例生成 — 工作流

## 输入与范围

| 来源 | 用途 |
|------|------|
| `project-analysis` | routes、auth、chainHints |
| 布局/侧栏 | `routeMenuMap`（见 [菜单导航与步骤.md](菜单导航与步骤.md)） |
| 主流程页面源码 | 按钮、表单、业务动词 |
| `api/`、`services/` | 判断创建/提交/流转动作 |

**产出**：`mainFlowInventory` + JSON 用例（见 [主流程识别与设计.md](主流程识别与设计.md)）。

**默认不做**：单字段校验、分页筛选组合、全路由穷举。

---

## 执行步骤

```
- [ ] 1. 读 project-analysis
- [ ] 2. 建立 routeMenuMap
- [ ] 3. 识别 UI 主流程 → mainFlowInventory
- [ ] 4. 编写用例（登录 + TC-FUNC-WF-*）
- [ ] 5. 智能编排（见 智能编排.md）
- [ ] 6. 验收（见 验收与输出.md）
- [ ] 7. 写入 test-artifacts/functional-cases/ 并更新 latest
```

### 步骤 2：routeMenuMap

从布局组件提取侧栏**可见文案**与 route；`/login` 标注 `navigation.type: direct`。

### 步骤 3：识别主流程

从 `chainHints`、页面业务动词归纳；**数量不设上限**；只读主流程涉及页面。

### 步骤 4：编写用例

- 登录：`TC-FUNC-AUTH-001`，`produces: ["sessionUser"]`
- 主流程：`ensure_session` → `click_menu` → 连续操作；`featureRefs` → `FLOW-*`
- 步骤与断言规则见 [菜单导航与步骤.md](菜单导航与步骤.md)

### 步骤 7：落盘

- `test-artifacts/functional-cases/functional-cases-{yyyyMMdd-HHmmss}.json`
- Schema：`_shared/功能用例结构.md`
