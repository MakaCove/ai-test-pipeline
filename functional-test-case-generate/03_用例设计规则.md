# 03 — 用例设计规则

> 功能覆盖验收见 **[06_功能覆盖与验收标准.md](06_功能覆盖与验收标准.md)**。  
> 清单与方法见 **[08_功能清单驱动设计.md](08_功能清单驱动设计.md)**、**[07_功能测试用例设计方法.md](07_功能测试用例设计方法.md)**。

## 优先级分配（通用规则）

| 优先级 | 适用条件 |
|--------|----------|
| P0 | 阻塞主流程：认证、核心业务 CRUD、关键任务/支付类操作 |
| P1 | 重要但可降级：详情、高级筛选、导出、辅助模块 |
| P2 | 配置、日志、只读查询 |

具体模块的 P0/P1 由 **project-analysis.modules[].priority** 或产品需求决定，**不在 skill 中写死模块名**。

## 命名与追溯

- `title`：`{模块} - {功能点名称} - {场景}`。
- `description`：用户操作 + 预期 UI 结果；可注明 `relatedApis`。
- `featureRef` / `featureRefs`：指向 `featureInventory[].id`（推荐必填）。
- 可串联场景补充 `dependsOnCases`、`produces`、`consumes`（见 `09_功能数据链路驱动设计.md`）。
- `tags`：业务标签 + 设计方法 tag（07 §1）。
- `designMethods`、`designRef`：设计依据（判定表规则、等价类分区等）。

## 页面分析（强制）

生成任一条用例前，该用例涉及的控件必须在源码中存在：

| UI 元素 | 如何写入 steps |
|---------|----------------|
| 按钮 | 可见文案，如页面上的「确认新增」 |
| 表单项 | `label` 或 `placeholder` |
| 菜单 | 侧栏/菜单项 title |
| 表格操作 | 操作列 link 文案 |
| 消息 | 断言 `ElMessage` / toast 文案 |

**禁止**用泛化 target（「确定」「提交」）替代未核实的文案。

## 场景从何而来

**不是**「每类页面固定 4 场景」，而是：

```
功能清单项 → 问：成功？失败？边界？状态？误操作？ → 1～N 条用例
```

参考 07 的方法选择表；简单功能 1 条即可，复杂功能多条。

## 操作步骤

| action | target 要求 |
|--------|-------------|
| navigate | 路由 path |
| fill / select | 真实 label 或 placeholder |
| click | 按钮/链接可见文案 |
| wait | 毫秒数，异步后使用 |
| screenshot | 关键步骤可选 |

常规用例 steps ≥3；端到端流程 ≥6。

## 断言

≥2 条，且验证本用例目标：

| 类型 | 适用 |
|------|------|
| url_contains | 路由、重定向 |
| text_contains | 标题、Message |
| element_visible / hidden | 弹窗、按钮、表格 |
| count_gte | 列表行数 |

## 账号与环境

- 账号来自 `project-analysis.auth` 或环境文档。
- 登录相关输入优先使用变量占位（如 `{{username}}`、`{{password}}`），避免在示例与产物中硬编码默认口令。
- `preconditions` 写明：后端可用、登录态、测试数据。

## teardown

创建/修改类用例：删除数据、或唯一编码（如 `{{timestamp}}`）+ description 说明可重复执行。

## 流程用例

当清单中存在**跨模块依赖**时，编写用例场景（07 §2.6）：

- 仅使用已列入 featureInventory 的功能点串联；
- 通过 `dependsOnCases` 标注上游用例依赖；
- 使用 `produces/consumes` 或 `steps.saveAs/useVar` 描述数据传递；
- 每步对应真实页面操作。

## 设计方法（按功能推导，非全局凑数）

| 方法 | 何时使用 |
|------|----------|
| 等价类 | 有输入域且存在有效/无效类 |
| 边界值 | 有长度/范围/分页约束 |
| 判定表 | 多条件决定 UI 结果（如登录） |
| 状态迁移 | UI 展示状态且可触发变更 |
| 组合测试 | 多因子筛选/表单 |
| 用例场景 | 跨页主路径 |
| 错误推测 | 易错交互（未选、重复点击） |
| 检查清单 | 冒烟：关键控件可见 |

**不要求**全文件某 tag 达到固定条数；要求的是**相关功能点**被合适的方法覆盖。
