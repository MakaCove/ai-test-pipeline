# 04 — 输出规范与文件命名

## 输出文件

- **路径**：`test-artifacts/functional-cases/functional-cases-{yyyyMMdd-HHmmss}.json`
- **编码**：UTF-8
- **格式化**：2 空格缩进

## 文件结构

### 元信息说明

| 字段 | 说明 |
|------|------|
| `navigationModel` | 固定 `menu-driven`（见 10） |
| `totalCases` | 实际用例数（结果值，非目标 KPI） |
| `featureInventory` | 功能清单，生成用例的依据 |
| `routeMenuMap` | 路由与侧栏菜单文案映射（见 10 §3） |
| `featureCoveragePercent` | P0 功能点覆盖率，验收目标 100% |
| `uncoveredFeatures` | 未覆盖功能 id 列表，应为 `[]` |
| `flowChains` | 可选：链路场景覆盖统计 |

**已废弃**：`targetMinCases` 及任何「条数下限」硬性字段。

## 用例扩展字段

| 字段 | 说明 |
|------|------|
| `featureRef` | 单功能点 id |
| `featureRefs` | 流程用例涉及的多个功能点 |
| `dependsOnCases` | 当前用例依赖的上游用例 id |
| `relatedApis` | 可选，便于与接口用例对照 |
| `produces` / `consumes` | 可选：用例级数据产出/消费变量 |

## latest 指针

更新 `test-artifacts/latest` 为当前时间戳（与接口用例共用时可覆盖）。
