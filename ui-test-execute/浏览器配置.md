# 浏览器配置

> Agent 执行 UI/功能测试前，**先解析用户指示**（浏览器来源 + 有头/无头 + 用例范围），再调用 `run-functional-tests.mjs`。

---

## 1. 两条默认规则（最重要）

| 维度 | **默认** | 用户明确指定时 |
|------|----------|----------------|
| 浏览器 | **自动**：固定 ms-playwright → 系统 Chrome | `--local-chrome` 强制 Chrome；`--profile playwright-headed` 强制自带 Chromium |
| 显示模式 | **有头**（弹出窗口，可见操作） | 说「无头 / headless / CI」→ `--headless` |
| 窗口尺寸（有头） | **启动即最大化** | 仅在用户明确要求固定尺寸时覆盖 |

**未写任何说明** → `auto-headed`（自动解析浏览器 + 有头 + slowMo 800 + 默认最大化）。

---

## 2. 浏览器解析优先级

执行器启动时会打印解析结果（Playwright 包路径、缓存目录、最终引擎）。

```
1. Playwright npm 包
   browserResolve.playwrightModulePaths → 当前项目 node_modules → 上级目录

2. 浏览器缓存（PLAYWRIGHT_BROWSERS_PATH）
   browserResolve.playwrightBrowsersPath → %LOCALAPPDATA%\ms-playwright

3. 引擎（engine: auto）
   fixed-chromium  → 固定缓存中有 chromium-{revision}
   system-chrome   → 配置的 Chrome 路径或系统 Google Chrome
   兜底            → Playwright 自带 Chromium
```

配置模板见 [_shared/ui-test-profile模板.md](../_shared/ui-test-profile模板.md)。

---

## 3. Profile 一览

配置：`test-artifacts/ui-test.config.json`

| profile | 浏览器 | 有头/无头 |
|---------|--------|-----------|
| **`auto-headed`（默认）** | 自动解析 | 有头 |
| `auto-headless` | 自动解析 | 无头 |
| `playwright-headed` | Playwright 自带 Chromium | 有头 |
| `playwright-headless` | Playwright 自带 Chromium | 无头 |
| `local-chrome-headed` | 系统 Google Chrome | 有头 |
| `local-chrome-headless` | 系统 Google Chrome | 无头 |

---

## 4. 用户话术 → 映射

| 用户说法 | 选用 |
|----------|------|
| 执行功能测试 / 跑用例 / 默认 / 看操作 | 不写 profile → **auto-headed** |
| 本地 Chrome / 系统 Chrome / 和我浏览器一样 | `--local-chrome` |
| 无头 / headless / 后台 / CI | `--headless` 或 `--profile auto-headless` |
| 本地 Chrome + 无头 | `--local-chrome --headless` |
| 前 N 条 | `--limit N` |
| 全部 | `--all` |

---

## 5. 标准 CLI

```bash
# 在包含 test-artifacts/ 的目录执行（scripts/ 与 test-artifacts/ 同级），不要 cd test-artifacts

# 默认：自动解析 + 有头
node scripts/run-functional-tests.mjs --limit 20

# 强制系统 Chrome + 有头
node scripts/run-functional-tests.mjs --local-chrome --limit 20

# 明确无头（仍走 auto 引擎选择）
node scripts/run-functional-tests.mjs --headless --limit 20

# 本地 Chrome + 无头
node scripts/run-functional-tests.mjs --local-chrome --headless --all
```

## 5.1 有头默认最大化约定

- `auto-headed` / `local-chrome-headed` / `playwright-headed` 默认都应使用：
  - `launchOptions.args: ["--start-maximized"]`
  - `contextOptions.viewport: null`
- 若用户明确指定窗口尺寸（例如 1366x768），再改为固定 `viewport`

---

## 6. 执行通道

- **批量 JSON 用例** → Playwright 脚本（禁止 MCP 替代）
- **单页探索** → MCP Browser

`profile`、`engine`（playwright-chromium / local-chrome）、有头/无头、`slowMo`、Playwright 包路径与浏览器缓存路径（启动日志）。
