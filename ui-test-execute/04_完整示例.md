## 执行过程（脚本执行器）

在包含 `test-artifacts/` 的目录执行：

```bash
node scripts/validate-functional-cases.mjs --strict --enforce-chain
node scripts/run-functional-tests.mjs --limit 20
```

执行器关键行为：

- 按 `executionOrder/dependsOnCases` 执行并维护变量池（`produces/consumes/saveAs/useVar`）。
- 使用分层选择器策略（`data-testid > role+name > 文案`）定位元素。
- 失败时自动落盘截图并写入 `ui-results-{ts}.json`。

**验证断言**：

1. `url_contains "/dashboard"` → `page.url()` 为 `http://localhost:5173/dashboard` → ✅ 通过
2. `element_visible "用户菜单或头像"` → 目标 locator 可见 → ✅ 通过

**结果**：✅ 通过，耗时 4.2 秒

链路执行说明：

- `TC-FUNC-WF-001` 依赖 `TC-FUNC-AUTH-001`，上游通过后才执行。
- 若 `sessionUser` 缺失，`TC-FUNC-WF-001` 标记为 ⏭️ 并记录链路变量缺失。
