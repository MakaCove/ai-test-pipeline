## 执行过程

**步骤 1**：`browser_navigate` → `http://localhost:5173/login`

- 等待 2 秒 → `browser_snapshot` → 登录页面加载成功，可见用户名输入框、密码输入框、登录按钮。

**步骤 2**：`browser_fill` → 在用户名输入框中填入 `{{username}}`

- `browser_snapshot` → 确认输入框已填入用户名变量对应值。

**步骤 3**：`browser_fill` → 在密码输入框中填入 `{{password}}`

- `browser_snapshot` → 确认密码已填入（显示为掩码）。

**步骤 4**：`browser_click` → 点击登录按钮

- `browser_snapshot` → 页面开始跳转，出现加载状态。

**步骤 5**：等待 2000 毫秒

- `browser_snapshot` → URL 变为 `http://localhost:5173/dashboard`，页面显示用户头像和用户名。

**验证断言**：

1. `url_contains "/dashboard"` → 快照 URL 为 `http://localhost:5173/dashboard` → ✅ 通过
2. `element_visible "用户菜单或头像"` → 快照中有 `[button "admin ▼"]` 元素 → ✅ 通过

**结果**：✅ 通过，耗时 4.2 秒

链路执行说明：

- `TC-FUNC-WF-001` 依赖 `TC-FUNC-AUTH-001`，上游通过后才执行。
- 若 `sessionUser` 缺失，`TC-FUNC-WF-001` 标记为 ⏭️ 并记录链路变量缺失。
