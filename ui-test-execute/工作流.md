# UI 测试执行 — 工作流

## 范围与前置

- **输入**：`test-artifacts/functional-cases/functional-cases-{latest}.json`
- **前置**：前端 + 后端运行；Playwright 已安装（`npm install`）
- **产物**：`test-artifacts/ui-reports/ui-report-{ts}.md` + 截图

## 执行通道

| 通道 | 场景 | 工具 |
|------|------|------|
| A（默认） | 批量 JSON 用例 | `scripts/run-functional-tests.mjs` |
| B | 单页探索 | MCP Browser |

批量执行**必须走通道 A**；浏览器配置见 [浏览器配置.md](浏览器配置.md)。

## 执行步骤

```
- [ ] 1. 定位用例文件
- [ ] 2. 确认前端可用
- [ ] 3. 选定 profile 与范围（--limit / --all / --module）
- [ ] 4. 调用 scripts/run-functional-tests.mjs
- [ ] 5. 输出摘要 + 报告路径
```

```bash
node scripts/run-functional-tests.mjs --limit 20
node scripts/run-functional-tests.mjs --local-chrome --limit 20
node scripts/run-functional-tests.mjs --headless --all
```

默认 `auto-headed`（固定 ms-playwright → 系统 Chrome，有头）；配置见 `test-artifacts/ui-test.config.json`。

## 执行器行为

- 分层选择器（`_shared/选择器策略.md`）
- 依赖排序、变量链、失败截图
- 生成 Markdown 报告
