# 01 — 执行范围与前置条件

## 输入

- **用例文件**：通过最新时间戳定位 `test-artifacts/functional-cases/functional-cases-{latest}.json`。
- 如果 latest 指针不存在，使用 Glob 查找 `test-artifacts/functional-cases/functional-cases-*.json`，取修改时间最新的文件。
- **Profile 配置**（可选）：`test-artifacts/ui-test.config.json`，见 `_shared/ui-test-profile模板.md`。

## 前置条件

- 前端开发服务器必须运行中（默认 `http://localhost:5173`，可通过用例文件的 `baseUrl` 字段覆盖）。
- 后端服务也必须运行中（UI 功能依赖后端 API）。
- Playwright 已安装（在包含 `package.json` 的项目根目录执行 `npm install`）；自带浏览器位于 `%LOCALAPPDATA%/ms-playwright/`。
- 用例文件通过机检脚本校验通过（建议）：`node scripts/validate-functional-cases.mjs --strict --enforce-chain`

## 执行通道

| 通道 | 适用 | 工具 |
|------|------|------|
| **A. Playwright 脚本** | 批量 JSON 用例、报告、截图 | `scripts/run-functional-tests.mjs`（与 `test-artifacts/` 同级） |
| **B. MCP Browser** | 单页临时探索 | `browser_navigate` / `browser_click` 等 |

批量执行功能用例 JSON 时**必须走通道 A**；浏览器类型由 **`05_浏览器与Profile选择.md`** 决定。

## Playwright 步骤映射（通道 A）

| 步骤 action | Playwright 操作 |
|-------------|-----------------|
| `navigate` | `page.goto(baseUrl + target)` |
| `fill` | `locator.fill(value)` |
| `click` | `locator.click()` |
| `select` | `locator.selectOption()` |
| `wait` | `page.waitForTimeout(ms)` |
| `screenshot` | `page.screenshot()` |

## MCP 工具映射（通道 B）

| 步骤 action | MCP 工具 |
|-------------|----------|
| `navigate` | `browser_navigate` |
| `fill` | `browser_fill` |
| `click` | `browser_click` |
| `select` | `browser_select_option` |
| `hover` | `browser_hover` |
| `wait` | 内置延时 |
| `press_key` | `browser_press_key` |
| `screenshot` | `browser_take_screenshot` |
| `scroll` | `browser_scroll` |

## 执行策略

- **默认 profile**：`playwright-headed`（Playwright 自带 Chromium + **有头 + 最大化窗口**）；用户指定本地 Chrome 或无头见 `05_浏览器与Profile选择.md`。
- **默认范围**：未指定时跑冒烟子集；用户说「前 N 条」用 `--limit N`，「全部」用 `--all`。
- **维持登录状态**：浏览器在用例之间保持登录状态，避免重复登录。
- **链路顺序优先**：存在 `dependsOnCases` 时，上游用例先执行；链路变量缺失时下游用例跳过并记录原因。

## 执行产物

- 人读报告：`test-artifacts/ui-reports/ui-report-{ts}.md`
- 机读结果：`test-artifacts/ui-reports/ui-results-{ts}.json`
- JUnit 报告：`test-artifacts/ui-reports/ui-junit-{ts}.xml`
- 截图证据：`test-artifacts/ui-reports/screenshots/`

## 终止策略

| 场景 | 行为 |
|------|------|
| 单个步骤失败 | 记录失败原因，继续执行当前用例的剩余步骤 |
| 断言失败 | 截图记录当前页面状态，继续执行下一个断言 |
| 登录失败 | 立即终止所有用例 |
| 页面无法加载 | 重试一次（等待 5 秒再试），仍失败则跳过该用例 |
| 链路变量缺失 | 跳过该用例并记录缺失变量（如 `projectName`） |
