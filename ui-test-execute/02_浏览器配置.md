# 浏览器配置

UI 执行器支持自动选择固定 Chromium 或系统 Chrome。

## 配置文件

- `test-artifacts/ui-test.config.json`
- 模板见：[shared/09_ui-test-profile模板.md](../shared/09_ui-test-profile模板.md)

## 常用命令

```bash
node scripts/run-ui-tests.mjs --limit 20
node scripts/run-ui-tests.mjs --local-chrome --limit 20
node scripts/run-ui-tests.mjs --headless --all
```
