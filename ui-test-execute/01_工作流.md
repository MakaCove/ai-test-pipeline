# 工作流（UI 执行）

1. 确认测试地址：用例 `meta.baseUrl` 或执行参数 `--base-url`（由用户提供，技能包不写死）
2. 运行校验：`node scripts/validate-artifacts.mjs --type ui`
3. 运行执行器：`node scripts/run-ui-tests.mjs`（或 `--base-url <地址>`）
4. 查看报告与截图：`test-artifacts/ui-reports/`

## 测试地址

- 来源优先级：`--base-url` > 用例 `meta.baseUrl`
- 无需事先确认服务是否启动；执行器直接访问给定地址，连不通则在用例/报告中体现失败
- 示例：`node scripts/run-ui-tests.mjs --base-url https://staging.example.com --limit 20`

## 关键点

- 默认**有头**模式（见 `test-artifacts/ui-test.config.json`），窗口**默认最大化**
- `click_menu` 优先使用 `routeMenuMap`
- 失败自动截图
