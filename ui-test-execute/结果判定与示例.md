# UI 测试 — 结果判定与示例

## 结果状态

| 状态 | 图标 | 含义 |
|------|------|------|
| 通过 | ✅ | 所有断言通过 |
| 失败 | ❌ | 步骤或断言失败 |
| 跳过 | ⏭️ | 登录失败、链路缺失、页面不可达 |

## 判定规则

- UI 断言类型见 `_shared/断言语法.md`
- 元素操作超时 10s；`wait` 按步骤 value 毫秒
- 失败自动截图：`ui-reports/screenshots/`
- 链路规则同 API 侧（`dependsOnCases` / `consumes`）

## 报告摘要模板

```
✅ UI 测试执行完毕
- 📋 用例文件：functional-cases-{ts}.json
- 📊 通过：N | ❌ 失败：N | ⏭️ 跳过：N
- 📁 报告：test-artifacts/ui-reports/ui-report-{ts}.md
- 📸 截图：test-artifacts/ui-reports/screenshots/
```

完整用例示例见 `functional-test-case-generate/完整示例.md`。
