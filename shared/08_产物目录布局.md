# 产物目录布局

```text
ai-test-pipeline/
├── scripts/
└── test-artifacts/
    ├── latest
    ├── project-analysis-{ts}.json
    ├── api-cases/
    │   └── api-cases-{ts}.json
    ├── ui-cases/
    │   └── ui-cases-{ts}.json
    ├── api-reports/
    │   └── api-report-{ts}.md
    └── ui-reports/
        ├── ui-report-{ts}.md
        └── screenshots/
```

## 执行约定

- 在仓库根目录执行脚本
- 默认读取 `./test-artifacts`
- 可通过 `--artifacts-dir` 覆盖
