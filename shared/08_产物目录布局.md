# 产物目录布局

```text
ai-test-pipeline/
├── scripts/
└── test-artifacts/
    ├── latest
    ├── project-analysis-{ts}.json
    ├── api-cases/
    │   └── api-cases-{ts}.json
    ├── ui-cases/
    │   └── ui-cases-{ts}.json
    ├── api-reports/
    │   └── api-report-{ts}.md
    └── ui-reports/
        ├── ui-report-{ts}.md
        └── screenshots/
```

## 执行约定

- 在**被测项目根目录**执行（该目录下应有 `test-artifacts/`）
- 默认读取 `./test-artifacts`（相对当前工作目录，不是 skill 包目录）
- 可通过 `--artifacts-dir` 覆盖
- PowerShell 链式命令用 `;`，不要用 `&&`：`cd D:\项目; node scripts/validate-artifacts.mjs --type api`
