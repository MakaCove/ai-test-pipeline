# UI 报告模板

生成 UI 测试报告时使用此模板。将 `{{占位符}}` 替换为实际数据。

**截图规则**：每条用例的截图必须紧跟在该用例明细下方，使用 Markdown 图片语法嵌入（路径相对报告文件，如 `screenshots/TC-UI-xxx_fail.png`）。

```markdown

**生成时间**：{{generatedAt}}
**用例来源**：{{caseFile}}
**项目分析**：{{sourceAnalysis}}
**测试地址**：{{baseUrl}}
**浏览器**：{{browser}}

---
```

## 说明

- 截图目录：`ui-reports/screenshots/`，报告中使用相对路径 `screenshots/<文件名>.png`。
- 截图类型：
  - **步骤截图**：用例步骤含 `action: "screenshot"` 时生成
  - **失败截图**：用例失败时自动附加
- **失败/跳过用例**与**用例明细与截图**均按「明细 → 截图」顺序排列；全量明细章节覆盖所有用例。
- **覆盖统计**块从 `ui-cases-*.json` 首元素 `coverage` 读取。
- 验收关注 **主流程 100% 覆盖**及执行通过率。
