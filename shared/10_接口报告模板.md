# 接口测试报告模板

生成接口测试报告时使用此模板。将 `{{占位符}}` 替换为实际数据。

每条用例须包含**入参（请求）**与**响应**，便于排查失败原因。

```markdown
# 接口测试报告

**生成时间**：{{generatedAt}}
**用例来源**：{{caseFile}}
**项目分析**：{{sourceAnalysis}}
**执行环境**：{{baseUrl}}

---

## 概览

| 指标 | 数值 |
|------|------|
| 总用例数 | {{total}} |

| 执行耗时 | {{duration}} |

## 说明

- **失败/跳过用例**与**用例请求与响应明细**均须展示完整入参和响应。
- 入参来源：实际发出的 `method`、`url`、`headers`、`body`（变量已替换后的值）。
- 响应来源：HTTP `status`、`headers`、`body`；请求异常时写 `error` 字段。
- 响应体过长时执行器可截断（默认约 8000 字符），并在 JSON 块末尾标注。
- **覆盖统计**块从 `api-cases-*.json` 首元素 `coverage` 读取。
- 验收关注 **主流程 100% 覆盖**及执行通过率，不以总用例数论达标。
