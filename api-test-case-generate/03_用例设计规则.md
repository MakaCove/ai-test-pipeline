# 03 — 用例设计规则

> 契约覆盖验收见 **[06_契约覆盖与验收标准.md](06_契约覆盖与验收标准.md)**。  
> 清单与方法见 **[08_端点契约驱动设计.md](08_端点契约驱动设计.md)**、**[07_接口测试用例设计方法.md](07_接口测试用例设计方法.md)**。

## 优先级分配（通用规则）

| 优先级 | 适用条件 |
|--------|----------|
| P0 | 认证、核心业务 CRUD、关键任务/交易类 API |
| P1 | 导出、辅助模块、复杂查询 |
| P2 | 配置、日志、只读统计 |

具体模块 P0/P1 由 **project-analysis.modules[].priority** 或产品需求决定，**不在 skill 中写死模块名**。

## 命名与追溯

- `title`：`{模块} - {接口摘要} - {场景}`。
- `description`：验证目标、前置、期望 status 与 body.code。
- `contractRef`：契约清单项 id。
- `scenarioRef`：契约场景 id（`SCN-*`）。
- 可串联场景补充 `dependsOnCases`、`produces`、`consumes`（见 `09_接口数据链路驱动设计.md`）。
- `tags`：业务 + 设计方法 tag（07 §1）。
- `designMethods`、`designRef`：设计依据。

## 单端点用例从何而来

**不是**「P0 不得少于 4 条」模板，而是：

```
读 Controller + DTO → 列出 scenarios[] → 每个 scenario 1 条用例
```

参考场景类型（08 §2.3）：

| 存在则写 | 场景 |
|----------|------|
| `@Valid` body | 每个必填字段校验失败 |
| query 筛选参数 | 各参数有效组合/单参 |
| requiresAuth | 无 token / 无效 token |
| 唯一键/业务 throw | 重复、不存在、非法状态 |
| 动作 endpoint | 合法触发 + 非法状态 |
| 分页 | 默认页、边界 pageSize |

简单端点 2～3 条、复杂端点 10+ 条均可。

## 变量串联

- 小驼峰：`token`、`projectId`、`versionId`…
- 登录 extract 路径以**实际响应 DTO** 为准。
- 鉴权：`Authorization: Bearer {{token}}`。
- 创建 POST：happy 场景 extract 主键。
- 唯一字段：`AUTO-{suffix}` 或 description 说明可重复策略。

## 断言（Spring Boot + 统一 ApiResponse 类项目）

成功至少：

```json
{ "field": "status", "operator": "eq", "expected": 200 },
{ "field": "body.code", "operator": "eq", "expected": 0 }
```

失败对照项目 `GlobalExceptionHandler`（示例，以实际为准）：

| 场景 | status | body.code |
|------|--------|-----------|
| 业务 IllegalArgumentException | 400 | 4001 |
| @Valid 校验 | 400 | 4002 |
| 未授权 | 401 | 4010 |

列表：先确认 `records` / `list` 字段名。

## Token 与测试账号

来自 `project-analysis.auth` 或环境配置；preconditions 注明可登录账号。

## 文件上传

`body: "__FORM__"` + `formFields`；注明测试文件策略。

## 流程用例（workflow）

当业务存在跨端点依赖时：

- `tags` 含 `业务流程`
- `contractRefs` 或 description 列出涉及端点
- 用 `dependsOnCases` 标注上游用例依赖
- 用 `produces/consumes` 标注变量产出与消费
- 不替代单端点的 contract 场景覆盖

## 设计方法（按契约推导）

| 方法 | 何时使用 |
|------|----------|
| 等价类 | 参数有效/无效类 |
| 边界值 | 长度、分页、数值界 |
| 判定表 | 登录、多条件提交 |
| 状态迁移 | 动作/PATCH 状态 |
| 组合测试 | 多 query 参数 |
| 业务流程 | 跨端点链 |
| HTTP语义 | Method/Content-Type |
| 契约校验 | 响应关键字段 type/exists |
| 错误推测 | 缺 header、畸形 JSON |
| 安全负向 | OWASP 可测项 |

**不要求**全文件某 tag 固定条数；要求相关契约场景被合适方法覆盖。
