# 接口用例 — 验收与输出

> 方法论：[主流程识别与设计.md](主流程识别与设计.md)

## 交付标准

| 优先级 | 标准 |
|--------|------|
| P0 | `mainFlowCoveragePercent` = 100% |
| P0 | request 与 DTO 一致；断言与 GlobalExceptionHandler 一致 |
| P0 | mock 字段名合法且有 `mockHints` |
| P1 | 变量链可执行；`executionOrder` 连续 |

## 输出路径

- `test-artifacts/api-cases/api-cases-{yyyyMMdd-HHmmss}.json`
- UTF-8，2 空格缩进
- Canonical Schema：`_shared/接口用例结构.md`

## coverage 必填

```json
{
  "mainFlowTotal": 4,
  "mainFlowsCovered": 4,
  "mainFlowCoveragePercent": 100,
  "uncoveredMainFlows": [],
  "orphanCases": 0,
  "mainFlowInventory": []
}
```

元信息推荐：`mockData`、`sourceAnalysis`、`totalCases`。

## 验收清单

- [ ] `mainFlowInventory` 有 `evidence`
- [ ] 每个 `suggestedCaseIds` 对应用例存在
- [ ] 每个 WF 用例有有效 `flowRef`
- [ ] 无硬编码 id/token/口令
- [ ] 智能编排已完成

## 反模式

- 每端点 H/V/A/E 四条模板
- 未读 DTO 写 body
- mock 字段名与 DTO 不一致
