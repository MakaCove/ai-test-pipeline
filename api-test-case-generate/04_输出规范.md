# 04 — 输出规范与文件命名

## 输出文件

- **路径**：`test-artifacts/api-cases/api-cases-{yyyyMMdd-HHmmss}.json`
- **编码**：UTF-8
- **格式化**：2 空格缩进

## 文件结构

**Canonical Schema**：`_shared/接口用例结构.md`（含 `endpointContracts`、`contractRef`、`scenarioRef`）。下文为摘要：

### 元信息说明

| 字段 | 说明 |
|------|------|
| `totalCases` | 实际用例数（结果值，非 KPI） |
| `endpointContracts` | 契约清单，生成依据 |
| `contractScenarioCoveragePercent` | P0 场景覆盖率，目标 100% |
| `uncoveredScenarios` | 未覆盖场景 id，应为 `[]` |

**已废弃**：`targetMinCases`、`≥ 2.5N` 类字段。

## 用例扩展字段

| 字段 | 说明 |
|------|------|
| `contractRef` | 契约清单项 id |
| `scenarioRef` | 场景 id |
| `extract` | 变量提取，供后续用例引用 |

## latest 指针

更新 `test-artifacts/latest` 为时间戳 `yyyyMMdd-HHmmss`。
