# 05 — 完整示例

## 输入

假设后端存在以下端点：

- `POST /api/v1/auth/login`：登录并返回 token
- `POST /api/v1/projects`：创建项目并返回 `id`
- `PUT /api/v1/projects/{id}`：修改项目
- `DELETE /api/v1/projects/{id}`：删除项目

并且 `GlobalExceptionHandler` 约定：

- 校验失败：`status=400`，`body.code=4002`
- 业务异常：`status=400`，`body.code=4001`
- 未授权：`status=401`，`body.code=4010`

## 示例要点

- 示例使用 `{{username}}/{{password}}` 与 `{{timestamp}}`，避免硬编码和脏数据冲突。
- 链路用例通过 `dependsOnCases` + `consumes/produces` 表达上游依赖关系。
- `totalCases` 是结果值，验收重点是契约场景覆盖率与链路覆盖率。
