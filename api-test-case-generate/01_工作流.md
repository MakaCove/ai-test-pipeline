# 工作流（API 用例生成）

1. 读取 `project-analysis`
2. 识别并确认 API 主流程
3. 生成 `mainFlowInventory`
4. 生成 API 用例 JSON，写入 `test-artifacts/api-cases/`
5. **生成完成后，向用户确认是否校验**（见下方「校验确认」）
6. 用户选择「执行校验」时，运行校验并反馈结果；选择「跳过」时不执行

输出目录：`test-artifacts/api-cases/`

Schema 见 [shared/04_接口用例结构.md](../shared/04_接口用例结构.md)。

## 校验确认（生成后必做）

用例 JSON 写入完成后，**不要自动执行校验**。先用如下话术询问用户：

```text
API 用例已生成：<文件路径>

是否现在运行校验？
- 执行校验：我将运行 `node scripts/validate-artifacts.mjs --type api`（或 `npm run validate`）
- 跳过校验：暂不校验，你可稍后手动执行；执行用例前仍建议先校验

请回复「执行校验」或「跳过校验」。
```

| 用户回复 | Agent 行为 |
|----------|------------|
| 执行校验 / 需要 / 是 | 运行 `node scripts/validate-artifacts.mjs --type api`，输出通过或失败明细 |
| 跳过校验 / 不需要 / 否 | 不运行校验；提醒「执行 `npm run test:api` 前建议先 `npm run validate`」 |
| 未明确回复 | 再次简短询问，不擅自执行或跳过 |
