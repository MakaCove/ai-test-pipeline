2. **发送请求**：`POST http://localhost:8080/api/v1/auth/login`，请求体 `{"username":"admin","password":"123admin"}`。
3. **收到响应**：`{ "code": 200, "data": { "token": "eyJhbGciOi...", "user": { "id": 1, "username": "admin" } } }`
4. **验证断言**：
   - `status eq 200` → 实际状态码 200 → ✅
   - `body.data.token exists` → 实际值非 null → ✅
5. **提取变量**：`token = "eyJhbGciOi..."`（存入运行时变量表，供后续用例使用）
