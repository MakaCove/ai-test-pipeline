## 执行过程

1. **变量替换**：从环境变量读取 `{{username}}/{{password}}`，替换请求体。
2. **发送请求**：`POST http://localhost:8080/api/v1/auth/login`。
3. **收到响应**：`{ "code": 0, "data": { "token": "eyJhbGciOi..." } }`
4. **验证断言**：
   - `status eq 200` → 实际状态码 200 → ✅
   - `body.code eq 0` → ✅
   - `body.data.token exists` → 实际值非 null → ✅
5. **提取变量**：`token = "eyJhbGciOi..."`。
6. **链路产出校验**：`produces=["token"]`，变量池中存在 `token` → ✅。
