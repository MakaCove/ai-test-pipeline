# 接口测试 — 结果判定与示例

## 结果状态

| 状态 | 图标 | 含义 |
|------|------|------|
| 通过 | ✅ | 所有断言通过 |
| 失败 | ❌ | 断言失败或请求异常 |
| 跳过 | ⏭️ | 依赖失败、变量缺失、服务不可达 |

## 判定规则

- 断言算子见 `_shared/断言语法.md`；执行器 `run-api-tests.mjs` 内置实现
- 路径取值：`body.data.items[0].name`
- 超时 30s；网络错误重试 1 次
- 链路：`dependsOnCases` 上游失败 → 跳过；`consumes` 缺失 → 跳过；`produces` 未产出 → 失败

## 报告摘要模板

```
✅ 接口测试执行完毕
- 📋 用例文件：api-cases-{ts}.json
- 📊 通过：N | ❌ 失败：N | ⏭️ 跳过：N
- 📁 报告：test-artifacts/api-reports/api-report-{ts}.md
```

完整 JSON 用例与链路示例见各 generate 技能的 `完整示例.md`。
