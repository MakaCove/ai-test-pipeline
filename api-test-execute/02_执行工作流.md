# 02 — 完整执行工作流

```
任务进度：
- [ ] 步骤 1：定位用例文件
- [ ] 步骤 2：执行前机检（schema/追溯/链路）
- [ ] 步骤 3：确认后端可用性
- [ ] 步骤 4：初始化执行环境
- [ ] 步骤 5：调用确定性执行器（按依赖顺序执行）
- [ ] 步骤 6：收集结果与统计
- [ ] 步骤 7：生成报告（执行器自动产出）
- [ ] 步骤 8：写入磁盘并输出摘要
```

## 步骤 1：定位用例文件

- 读取 `test-artifacts/latest` 获取最新时间戳。
- 定位文件：`test-artifacts/api-cases/api-cases-{时间戳}.json`。
- 如果 latest 不存在，使用 Glob 匹配 `api-cases-*.json`，按修改时间取最新。
- 解析 JSON 文件，验证第一个元素包含 `"schema": "ai-test-pipeline/api-case/v1"`。

## 步骤 2：执行前机检（强烈建议）

- 执行 `node scripts/validate-api-cases.mjs --strict`。
- 发布前或主分支门禁建议：`node scripts/validate-api-cases.mjs --strict --enforce-chain`。
- 机检失败时停止执行并先修复产物。

## 步骤 3：确认后端可用性

- 尝试发送 `GET {基础地址}/actuator/health` 或直接请求根路径。
- 如果不可达，提示用户启动后端服务后重试。

## 步骤 4：初始化执行环境

- 确定 `baseUrl`（默认 `http://localhost:8080`，可通过用例 meta、`--base-url` 或用户输入覆盖）。
- 执行器自动初始化运行时变量表（注入 `username`/`password`/`timestamp` 系统变量）。

## 步骤 5：调用执行器（确定性脚本）

> 在包含 `test-artifacts/` 的目录执行，**不要** `cd test-artifacts`。

```bash
node scripts/run-api-tests.mjs                 # 默认读 latest，执行全部
node scripts/run-api-tests.mjs --limit 20      # 仅前 20 条（按 executionOrder）
node scripts/run-api-tests.mjs --module orders # 指定模块
node scripts/run-api-tests.mjs --base-url http://localhost:8080
```

执行器对每条用例固定执行（无需 Agent 手写临时脚本）：

1. **依赖检查**：`dependsOnCases` 上游失败 → 跳过并记录「上游失败传递」。
2. **变量消费检查**：`consumes` 变量缺失 → 跳过并记录「链路变量缺失」。
3. **模板变量检查**：`{{var}}` 未解析 → 跳过并记录「模板变量未解析」。
4. **变量替换**：递归替换 `path`、`headers`、`body` 中的 `{{变量名}}`。
5. **发送请求**：Node 内置 `fetch`，30s 超时，网络错误重试 1 次。
6. **断言判定**：按 `_shared/断言语法.md` 算子逐条判定。
7. **提取变量**：`extract` 按响应路径取值入池。
8. **produces 校验**：声明产出的变量未得到则标记失败。

## 步骤 6：收集结果与统计

执行器自动汇总：总数、通过、失败、跳过、通过率、总耗时；链路用例数与链路通过率。

## 步骤 7：生成报告（执行器自动产出）

- Markdown：`_shared/接口报告模板.md` 结构，含覆盖率 + `flowChains` + 失败明细。
- 机读结果：`api-results-{ts}.json`；JUnit 报告：`api-junit-{ts}.xml`。

## 步骤 8：写入磁盘并输出摘要

- 报告：`test-artifacts/api-reports/api-report-{yyyyMMdd-HHmmss}.md`
- 机读结果：`test-artifacts/api-reports/api-results-{ts}.json`
- JUnit 报告：`test-artifacts/api-reports/api-junit-{ts}.xml`
- 回归对比（可选）：`node scripts/compare-results.mjs --kind api`
- 同时输出摘要到对话中（通过/失败/跳过 + 报告路径）。
