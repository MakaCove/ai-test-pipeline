# 接口测试执行 — 工作流

## 范围与前置

- **输入**：`test-artifacts/api-cases/api-cases-{latest}.json`（或 Glob 最新）
- **前置**：后端运行中；数据库/种子数据就绪；网络可达
- **产物**：`test-artifacts/api-reports/api-report-{ts}.md`

## 链路规则

- `dependsOnCases` 上游失败 → 跳过
- `consumes` 缺失 → 跳过
- `produces` 未产出 → 失败

## 执行步骤

```
- [ ] 1. 定位用例文件（读 latest）
- [ ] 2. 确认后端可用（health 或根路径）
- [ ] 3. 调用 scripts/run-api-tests.mjs
- [ ] 4. 输出摘要 + 报告路径
```

> 在包含 `test-artifacts/` 的目录执行，**不要** `cd test-artifacts`。

```bash
node scripts/run-api-tests.mjs
node scripts/run-api-tests.mjs --limit 20 --module orders
node scripts/run-api-tests.mjs --base-url http://localhost:8080
node scripts/run-api-tests.mjs --ids TC-API-AUTH-001,TC-API-ORDERS-001
```

## 执行器行为

1. 注入 `mockData`、`username`/`password`、`timestamp`
2. 依赖排序 → 逐条 HTTP 请求
3. 断言（`_shared/断言语法.md`）→ extract 变量
4. 生成 Markdown 报告

## 终止策略

| 场景 | 行为 |
|------|------|
| 单用例失败 | 记录后继续 |
| 登录失败 | 建议终止（下游依赖 token） |
| 网络错误 | 重试 1 次 |
| 变量缺失 | 跳过 |
