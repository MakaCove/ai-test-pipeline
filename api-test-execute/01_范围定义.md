# 01 — 执行范围与前置条件

## 输入

- **用例文件**：通过最新时间戳定位 `test-artifacts/api-cases/api-cases-{latest}.json`。
- 如果 latest 指针不存在，使用 Glob 查找 `test-artifacts/api-cases/api-cases-*.json`，取修改时间最新的文件。

## 前置条件

- 后端服务必须运行中（默认 `http://localhost:8080`，可通过用户输入覆盖）。
- 如果项目使用数据库，确保测试数据库已初始化且有种子数据。
- 网络可达后端地址。

## 执行策略

- **默认**：执行所有用例，按用例文件中的顺序执行。
- **用户可指定**：按模块、优先级、标签过滤。
  - 例如：「只执行 P0 优先级的用例」「只执行 auth 模块的用例」。

## 终止策略

| 场景 | 行为 |
|------|------|
| 单个用例执行失败 | 记录失败原因，继续执行下一个用例 |
| 登录用例失败 | 立即终止（所有需要认证的用例都依赖 token） |
| 网络连接失败 | 重试一次，仍失败则跳过所有剩余用例 |
| 变量未定义 | 跳过该用例（如 `{{projectId}}` 尚未被前置用例提取） |
